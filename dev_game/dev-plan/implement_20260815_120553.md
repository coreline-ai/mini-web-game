# implement_20260815_120553.md

작성 일시: `2026-08-15 12:05:53 KST`

이 문서는 **"한 번의 실행이 사람 개입 없이 스스로 재시도하며 끝까지 간다"** 를 목표로 하는 아트 파이프라인 보완의 범위를 고정한다. 근거는 이번 세션 실패 12건의 전수 분류와 전문가 재검토다: 실패는 스킬 경계가 아니라 **"생성 1회 → 몇 분 뒤 게이트 발각 → 사람 개입"** 패턴에 뭉쳐 있고, 재시도는 확률적 실패에만 유효하며 구조적 실패(시트)는 기본값 제거가 유일한 해법이다.

## 개발 목적

- 재시도로 고칠 수 없는 **구조적 실패 클래스(다프레임 시트)를 기본값에서 제거**한다.
- 생성 직후 **즉시 검증 + 실패 사유를 주입한 자동 재시도(자산당 ≤2회)** 로 확률적 실패(선명도·팔레트·과투명)를 실행 내부에서 흡수한다.
- 즉시 검증과 게이트가 **같은 임계값**을 쓰도록 공유 lib로 추출한다 — 둘이 어긋나면 "즉시 통과 → 게이트 실패"가 재발한다.
- 수동으로 반복해온 결정론적 후처리 2종(크로마 테두리 정화, 런타임 WebP 출력)을 파이프라인에 편입한다.
- 자동 생성 기획문서가 hybrid 게임에서 거짓 문서가 되는 문제에 재작성 의무를 명시한다.
- 최종 실패 시 처음부터가 아니라 실패 지점부터 재개할 수 있게 한다(`--from`).

## 잔여 리스크 / 후속 과제

- 재시도는 확률을 낮출 뿐 0으로 만들지 못한다. 추정: 무개입 완주 확률 ~12% → ~84% (자산당 결함 10%, 재시도 2회 기준 어림값).
- 재시도는 이미지당 최대 +80초·쿼터 2회를 쓴다. 상한이 있으므로 폭주하지 않지만, 실행 시간 편차는 커진다.
- hue 검증은 단색 계열 버튼에 유효하며, 다색 장식 버튼은 주조색 판정이 흔들릴 수 있다 — 허용 거리를 보수적으로 잡고 오탐 시 로그로 관찰한다.
- 절차적 버튼 기본화(계약 개정 필요)와 `validate_spritesheet_manifest.py` 게이트 승격은 별도 과제로 유지.
