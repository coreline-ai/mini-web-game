# implement_20260815_113232.md

## 개발 목적

- imagegen을 호출하지 않고도 `production-demo` + imagegen provenance가 부여되는 **위조 경로를 차단**한다.
- `codex exec`가 실패했는데 이전 산출물이 남아 있으면 성공으로 판정하는 **거짓 성공을 제거**한다.
- 선언한 Node 엔진(>=18)과 실제 요구(globSync = Node 22+)의 **불일치를 해소**한다.
- 셸 실행이 가능한 임의 호스트가 쓸 수 있도록 설치·실행 경로를 문서화한다.
- 아트를 만들지 않는 custom-loop가 이미지젠 preflight로 막히지 않게 한다.
- 신규 게임과 문서 상수 검사를 CI가 실제로 돌게 한다.
- 511줄 단일 파일인 `game-asset-creation`을 references로 분리한다.

## Phase 1. P0 — imagegen provenance 위조 차단

### 목표
- 디스크에 파일이 있다는 사실만으로 imagegen 출처가 부여되는 경로를 없앤다. 출처는 **실제 실행의 영수증**으로만 성립한다.

### 설계
| 요소 | 규칙 |
|---|---|
| 영수증 | 생성 성공 시 `provenance`에 `outputSha256`·`generatedAt`·`runId` 기록 |
| `promoteExisting` | provenance를 **신규 생성하지 않는다**. 기존 provenance가 없으면 `quality: 'draft'`로 두고 목록 보고 |
| `--skip-existing` | 파일 검증에 더해 **manifest provenance 존재 + `outputSha256` 일치**를 요구. 불일치면 재생성 |

### 구현 태스크
- [x] `imagegenProvenance()`에 `outputSha256`·`generatedAt`·`runId` 필드 추가(생성 경로 전용)
- [x] 실행 단위 `runId` 생성(프로세스 1회)
- [x] `promoteExisting()`에서 `imagegenProvenance()` 호출 제거 — 기존 provenance만 유지, 없으면 draft
- [x] `reusableExisting()`에 SHA 대조 인자 추가, 호출부에서 manifest 엔트리를 넘김
- [x] 영수증 없는 자산 목록을 종료 시 보고

### 자체 테스트
- [x] **위조 재현이 실패**: 임의 PNG + `--skip-existing` → provenance 미부여, quality draft

- 기존 16개 게임의 provenance에는 영수증이 없다. 게이트는 현행 필드만 요구하므로 통과하지만, **소급 증명은 불가능**하다. 각 게임을 재생성할 때 영수증이 붙는다.
- 영수증은 "이 파이프라인이 이 파일을 만들었다"를 증명할 뿐, 이미지가 실제로 내장 image_gen에서 왔는지는 codex CLI를 신뢰하는 전제 위에 있다. 그 신뢰 경계는 문서에 남긴다.
- 셸 없는 호스트는 여전히 지원 대상이 아니다.
