# 독립 검토 — receipt-attestation

- reviewer: `production-pass-receipt-qa` (기계 판정)
- 판정: `PASS`

## 증명된 것

다섯 갈래 결함 주입이 각각 해당 대조군을 RED로 만들고, 위조 차단은 실제 키쌍으로 확인했다.
무서명·변조·타 키 세 경우가 모두 `invalid`이며, 정상 서명만 `pass`다.

## 이 작업이 닫지 **않은** 것

키가 없으면 아무것도 닫히지 않는다. 지금 상태는 **기계가 준비됐고 스위치가 꺼져 있다**이며,
영수증 8건은 여전히 `unattested`다. 그것을 `pass`로 두는 것이 옳다 — 전환 전이므로 무서명이
결함이 아니고, 상태 문구가 그 사실을 스스로 말한다.

켜는 순간 8건이 무효가 되고 CI가 재발급해야 한다. 이 비용은 위조를 실제로 닫는 대가이며,
켤지 말지는 저장소 소유자의 결정이다. 비밀키를 내가 만들어 두지 않은 것도 같은 이유다 —
비밀키가 로컬에 존재하는 순간 이 구조는 무의미해진다.

## 대조군 자기 지적

이 작업에서 대조군 설계로 두 번 틀렸다(변조 필드 선택, 지문 중복). 둘 다 harness가 잡았다 —
"다른 이유로 죽은 RED는 통과가 아니다"와 지문 배타성 검사가 각각 제 일을 했다.
