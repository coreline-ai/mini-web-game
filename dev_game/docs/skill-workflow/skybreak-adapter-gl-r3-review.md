## 검토자가 확인한 것

1. **위반을 게이트가 잡았고, 넓히지 않고 되돌렸다.** 선언 없는 편집은 `E_PASS_DRIFT`로 저장소
   전체 게이트를 멈췄다. 되돌린 뒤 supersede를 선언해 다시 했다. 승인 범위를 사후에 넓히는
   경로는 쓰지 않았다.
2. **절차 실패 두 건이 기록됐다.** 영수증을 범위에 넣어 만든 순환(`E_PASS_DRIFT` 예정),
   선언 전 편집으로 만든 `E_NO_CHANGE`. 둘 다 구현 기록에 남아 다음 사람이 같은 순서를
   반복하지 않는다.
3. **변경 내용은 앞 커밋의 세 게임과 동일하다.** 파일 5개에서 하드코딩된 실행 인자 배열을
   게임 안 공용 헬퍼 호출로 교체했을 뿐이며, 게임 로직·아트·매니페스트는 손대지 않았다.
4. **근거의 한계가 적혀 있다.** 어댑터 단계의 효과는 측정되지 않았고(10/10 vs 10/10), 그 사실이
   구현 기록과 커밋 메시지에 남는다. 측정된 개선으로 포장하지 않았다.

## 남는 위험

이 변경으로 게이트 전체 통과율이 올라간다는 보장은 없다 — 기전은 확인됐지만 어댑터 단계의
효과는 미측정이다. 다음 판별 측정은 CI nightly의 전체 게이트 결과다(매번 새 컨테이너라 로컬
