영수증 4건은 게이트가 직접 낸 판정이며 재실행으로 재현된다. 각 영수증의 `qaRunId`가 그
실행이 만든 세션과 일치함을 확인했다.

`iron-courier-last-line`은 사전 스윕에서 이미지 품질 5건으로 차단됐고 전체 게이트를 돌리지
않았다 — 통과할 수 없는 것이 확정된 상태에서 브라우저 게이트를 도는 것은 의미가 없다.
영수증은 발급되지 않았고 상태는 `legacy-pass` 그대로다(allowlist에 남아 있음).

**범위 판단에 대한 의견:** 배치 2에서 멈춘 것은 타당하다. 이 작업의 목적은 게이트가 실제
작업에서 작동함을 증명하고 `legacy-pass`의 미증명성을 걷어내는 것인데, 전자는 달성됐고
후자는 게임 수에 비례하는 단순 반복이다. 남은 8개는 스킬 강화가 아니라 데이터 이전이며,
우선순위를 다시 잡는 것이 옳다.
