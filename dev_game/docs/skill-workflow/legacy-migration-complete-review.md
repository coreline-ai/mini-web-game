# 독립 검토 — legacy-migration-complete

- reviewer: `production-gate` (기계 판정)
- 판정: `PASS`

15건은 게이트가 직접 통과시킨 것이며 재실행으로 재현된다. 각 영수증의 `qaRunId`가 그 실행이
만든 세션 리포트와 일치한다.

미통과 1건은 전체 게이트를 실제로 돌려 확정했다 — 사전 스윕 예측만으로 결론 내리지 않았다.
영수증이 없고 미검증 표식이 남아 `invalid`이며, 실패를 통과로 세탁하지 않았다.

## 이 작업이 바꾼 것

`legacy-pass`는 이 저장소가 제도 이전 게임을 인정하려고 만든 임시 상태였고, 지문이 없어
현재성을 증명하지 못한다는 한계를 계속 문서에 적어 왔다. 그 상태의 게임이 **0이 됐다.**
남은 allowlist 항목 1개는 게이트를 통과하지 못한 게임이므로 `pass`가 아니며, 통과하는 날
목록과 파일을 함께 지우면 개념이 코드에서 사라진다.

## 남은 것

`unknown` 3개와 `invalid` 2개는 모두 `asset-plan.json`이 없는 세대이거나 프롬프트가 소실된
게임이다. 통과시키려면 프롬프트를 새로 써야 하고, 그것은 기계가 대신할 수 없다.
