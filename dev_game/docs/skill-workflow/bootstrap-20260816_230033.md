## As-built

- `skill_task_gate.mjs`에 여섯 상태의 단방향 상태 머신을 구현했다.
- `--target` 구현 범위와 `--allow` 전체 범위를 시작 전에 분리해 기록한다. 증거 파일만 만들어
  IMPLEMENTED로 진행할 수 없다.
- 시작 snapshot과 현재 Git-visible 파일의 byte SHA를 비교하며, 정확한 경로 또는 `/` 경계
  하위 경로만 허용한다. prefix가 비슷한 다른 파일은 범위 밖이다.
- DOCUMENTED·SKILL_COMPARED·REVIEWED는 서로 다른 비어 있지 않은 증거 파일을 요구한다.
- reviewer는 implementer와 다른 ID여야 하며, 비교 verdict는 `MATCH`만 진행할 수 있다.
- PASS 시 허용 범위 snapshot과 상태 seal을 원자적으로 기록한다. 이후 변경은 `verify`와 다음
  `start` 모두 차단한다. 의도적 후속 수정은 편집 전에 `--supersede`를 선언한다.
- 루트 `AGENTS.md`와 `dev_game/docs/skill-task-gate.md`에 같은 상태·명령·중단 규칙을 기록했다.
