# 스킬·계약 정합성 비교 — preview-exit-cleanup

## 비교 대상
- `skills/game-factory/SKILL.md` — 게이트 실행 명령과 완료 판정
- `skills/game-polish/SKILL.md` — 재캡처·재게이팅 루프
- `dev_game/docs/post-production-qa-contract.md` §3.1 — 자동 게이트의 적용 범위

## 대조

| 요구 | 실제 | 판정 |
|---|---|---|
| 게이트는 반복 실행 가능해야 한다 (polish는 같은 명령을 계속 돌린다) | 실패한 실행이 포트를 잡은 채 남아 **다음 실행을 오염**시켰다 → exit 훅으로 닫았다 | MATCH |
| 게이트는 자기 흔적을 남기지 않는다 | 미검증 표식은 성공 시 지우고, 프리뷰는 종료 경로 전부에서 죽인다 | MATCH |
| 실패는 조용히 넘어가지 않는다 | 실패 자체는 그대로 exit 1이다. 바뀐 것은 **정리**뿐이며 판정은 건드리지 않았다 | MATCH |
| 검사를 지워도 통과하지 않게 한다 | 배선 대조군 2개 추가(exit 훅 존재 + 첫 브라우저 게이트보다 앞) | MATCH |
| 필요 없는 변경을 하지 않는다 | `custom-loop-full-qa`는 `throw` 경로라 같은 결함이 없어 손대지 않았다 | MATCH |

## 앞 task와의 관계

`preview-identity-guard`는 **증상**(남의 서버를 검사하고 통과)을 잡았고, 이 task는 **원인**(실패한
게이트가 프리뷰를 고아로 남긴다)을 닫는다. 둘은 겹치지 않는다 — 신원 검증은 외부 서버가 어떤
이유로 포트를 잡아도 유효하고, exit 훅은 이 저장소가 스스로 유령을 만들지 않게 한다.
