## 스킬 문서 변경 없음

스킬이 부르는 명령과 완료 기준은 그대로다. 바뀐 것은 그 명령의 **실패가 설명 가능해졌다는 것**과
소프트웨어 GL 경로의 기본값이다. 계약 K-2의 "미확정" 항목은 이 task로 답이 나왔으므로 후속
task에서 갱신한다(이 task의 선언 범위에 계약 문서가 없다).
