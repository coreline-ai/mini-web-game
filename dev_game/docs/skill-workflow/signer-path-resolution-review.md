## 증명된 것

- CI와 동일한 호출로 서명기가 통과한다. 대조군이 그 형태를 그대로 실행하며, cwd 부모 후보를
  제거하면 RED가 된다.
- 서명기가 영수증 기준으로 트리를 찾으므로 대조군이 실제 저장소를 건드리지 않는다.

## 앞 작업에 대한 판정

`receipt-attestation`은 **성공 경로를 시험하지 않은 채 통과했다.** 오류 경로(키 없음, 영수증
없음, 재서명)만 대조군에 있었고, 정작 CI가 실제로 하는 호출은 반드시 실패하는 상태였다.
대조군이 있다는 것과 옳은 대조군이 있다는 것은 다르다.
