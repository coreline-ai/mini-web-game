# 스킬·계약 정합성 비교 — lastlight-fx-regen-r2

| 요구 | 실제 | 판정 |
|---|---|---|
| 나쁜 아트는 **재생성**한다 (patch-around 금지) | 프롬프트를 새로 쓰고 재생성 — 자산을 손보지 않았다 | MATCH |
| 요구치를 낮춰 통과시키지 않는다 | `minWidth 1024` 를 낮추는 대신 게임의 PNG 배송 모델을 지켰다 | MATCH |
| 캡처에서 나온 결함은 고치고 재캡처 | 레이아웃 2종을 고치고 3 뷰포트 재검증 | MATCH |
| 오탐은 검사기 쪽을 의심한다 (§0.1) | 진행 바 겹침은 설계임을 기하로 확인 후 예외 선언 | MATCH |
| 완료는 게이트 통과로만 | `production-gate` exit 0 후 영수증 발급 | MATCH |

## 도구 수정이 함께 필요했던 이유

- `codex-imagegen` 의 빈 프롬프트 가드가 **계획 전체**를 요구해 targeted 재생성을 막았다.
  선택 항목만 보도록 좁혔다. 이 수정이 없으면 복원된 계획으로는 어떤 자산도 다시 만들 수 없다.
- `LayoutRegistry` 가 `allowOverlapWith` 를 검사기로 전달하지 않았다. 검사기에는 그 장치가
  있는데 게임이 쓸 수 없는 상태였다.

두 가지 모두 "스킬이 시키는 일을 도구가 못 하게 막고 있던" 경우다.
