## 증명된 것

세 갈래 결함 주입이 각각 해당 대조군을 RED로 만들고, 실제 실행으로도 확인했다.

```
--id a1    → 생성 묶음을 쪼개는 재생성이다: sheet0001 선택 a1 / 나머지 a2
--id 'a*'  → 통과   --id solo → 통과
```

배선 대조군은 호출 지점을 정규식으로 본다. 앞 작업에서 문자열 포함 검사가 **정의와 호출을
구분하지 못해** 공허했던 전례가 있어, 같은 실수를 반복하지 않도록 처음부터 그렇게 썼다.

## 이 작업이 정정한 것

앞 작업의 증거 문서와 커밋 메시지가 "manifest는 어느 시트에서 잘렸는지 기록하지 않는다"고
단정했다. 실제로는 `promptHash` 공유로 기록돼 있었다. **데이터를 더 보기 전에 결론을 적은
것**이며, 이번 문서에서 명시적으로 정정했다.

## 남은 한계 (숨기지 않음)

- 묶음 전체 재생성에는 구성원별 프롬프트가 필요하고, 시트 프롬프트를 자산별로 나누는 것은
  기계가 할 수 없다.
- `art-prompts.md` 블록과 묶음의 연결은 **증명되지 않는다.** 해당 해시는 손으로 쓴 것이라
  현재 공식으로도 `sha256(prompt)`로도 재현되지 않는다. 추정으로 붙이면 엉뚱한 프롬프트로
  재생성하게 되므로 붙이지 않는다.
