# 독립 검토 — adapter-gl-drift-closure

- reviewer: `skill-task-gate` (기계 판정)
- 판정: `PASS`

## 검토자가 확인한 것

1. **drift의 원인이 정확히 서술됐다.** PASS 시점 스냅샷이 `MISSING`이었고 삭제 커밋으로 키가
   사라졌다 — 게이트 구현(`snapshot()`이 git 목록 기준, 없는 파일은 `MISSING`)과 일치한다.
2. **해시를 고쳐 맞추지 않았다.** 상태 파일은 손대지 않고 supersede로 닫았으며, 옮겨 온 drift가
   기록된다.
3. **봉인을 늘리지 않았다.** `qa/`와 영수증을 범위에서 뺐다. 넣었다면 다음 게이트 실행이 같은
   교착에 빠진다 — 오늘 그 교착을 두 번 겪었다.
4. **규칙이 실행 가능하다.** "`git rm` → PASS → 커밋" 세 단계로 적혀 있어 다음 사람이 그대로
   따를 수 있다. 추상적 교훈("트리를 일치시켜라")만으로는 오늘 이 실수를 막지 못했다.

## 남는 위험

이 종결은 절차 문제만 닫는다. 게임 네 개는 여전히 영수증이 없는 상태(`invalid`)이며, 재게이팅이
성공해야 라우팅이 복구된다. 그 결과는 이 문서가 아니라 영수증이 증명한다.
