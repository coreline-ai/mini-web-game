# 01 · Game Design Document — Night Market Wok

## Concept

야시장 국수 포장마차의 요리사가 되어, 손님이 주문한 국수를 **재료 순서대로** 조리해 인내심이 다하기 전에 내주는 한손 세로 아케이드.

- **One-line pitch:** 주문을 읽고, 재료를 순서대로 탭하고, 손님이 떠나기 전에 내준다.
- **Core input:** 탭 전용. 하단 재료 버튼 5개와 손님 좌석 3개만 누른다. 드래그·이동·조준이 없다.
- **Core fun:** 여러 주문을 동시에 머리에 이고, 순서를 틀리지 않으면서 인내심 타이머를 이기는 압박.
- **Fail condition:** 손님 **3명**이 인내심이 다해 떠나면 종료. 오조작 한 번으로는 죽지 않는다.

## 30-second core loop

1. 좌석에 손님이 앉고 머리 위에 요리명이, 티켓 패널에 **재료 순서**가 뜬다.
2. 티켓의 다음 단계가 링으로 강조된다. 해당 재료를 탭한다.
3. 맞으면 단계가 체크되고 웍이 반응한다. 틀리면 **그 그릇만 처음부터**(주문은 그대로) + 인내심 2.2초 감소.
4. 마지막 재료까지 맞추면 그릇이 손님에게 날아가고 점수·콤보가 오른다.
5. 좌석이 비면 새 손님이 앉는다. 좌석을 탭해 다른 주문으로 초점을 옮길 수 있다.

## Controls

| 입력 | 동작 |
|---|---|
| 하단 재료 버튼 탭 | 현재 초점 주문에 그 재료를 추가 |
| 손님 탭 | 초점 주문 전환 (동시 주문 관리) |
| 우상단 Ⅱ | 일시정지 |

## Scoring

- 재료 1단계 성공: 12점
- 서빙 완료: 120점 × 콤보 배수 + (콤보 스택−1) × 35점
- 콤보 배수: 연속 서빙 2회당 +1, 최대 5배. 오조작 또는 손님 이탈 시 0으로 초기화.

## Difficulty

난이도 입력은 **경과 시간과 누적 서빙 수**뿐이다. 남은 인내심·점수·콤보처럼 플레이어가 회복시킬 수 있는 값은 난이도에 절대 반영하지 않는다(잘할수록 쉬워지는 역전 방지).

| 축 | 곡선 |
|---|---|
| 레시피 길이 | 서빙 0/6/14회에서 최대 3→4→5단계로 해금 (시작 티어가 2단계면 레시피가 1종뿐이라 초반 주문이 전부 동일해짐) |
| 인내심 | 서빙당 260ms 감소, 하한 5.2초 |
| 손님 도착 간격 | 초당 18ms 감소, 하한 0.9초 |
| 손님 유형 | 단골 1.0 / 급한 학생 0.72 / 까다로운 상인 0.86 배 인내심 |

## Fail & retry

3스트라이크 소진 시 GameOver 씬으로 이동하며 점수와 서빙 수를 전달한다. 재시작은 완전 초기화(주문·콤보·스트라이크·좌석 전부 리셋)다.

## Content list

- 재료 5종: 면 · 육수 · 파 · 고기 · 계란
- 레시피 6종: 기본/파/고기/계란 국수, 특 국수, 야시장 정식
- 손님 3종: 단골 · 급한 학생 · 까다로운 상인
- 스테이지 배경 3종 (서빙 수에 따라 크로스페이드)
