## 수정 (심각도 순)

**오디오 (심각도 2)** — `scripts/make-audio.mjs` 신설, 7개 파일 전량 재합성.

| 지표 | 이전 | 이후 |
|---|---|---|
| 샘플레이트 | 16k(BGM) / 22k(SFX) | **44.1k 전부** |
| BGM 루프 | 6.0s | **22.8s** (4마디 코드 진행) |
| 피크 레벨 | 0.16~0.50 | **0.80~0.90** |
| `wreck` 시작 팝 | 0.150 | **0.000** |
| 루프 이음매 불연속 | 0.0154 | **0.0026** |

방식: 배음 스택(배음별 개별 감쇠 + 약간의 비배음성), 코사인 페이드 엔벨로프, 슈뢰더 리버브 축약판, 루프 꼬리 크로스페이드. 결정적 노이즈 시드라 재실행해도 같은 파일이 나온다.

**배 겹침 (심각도 2)** — `ShipRouting.spawn()`이 순번이 아니라 **점유 여부**로 항로를 배정하고, 빈 항로가 없으면 생성을 거부한다. 검증: 4회 강제 생성 → `[true,true,true,false]`, 살아있는 배의 항로 `[0,1,2]` 중복 0.

**레이아웃 (심각도 3)**
- 항로 3개를 전부 수평선 아래로(`y 0.527 / 0.593 / 0.659`), 좌·우·좌 엇갈림
- 배가 화면을 가로질러 오며 다른 배를 통과하던 문제 → 제자리 페이드인(진입 거리 70u)
- 배 크기 190 → 100 CSS, 인내심 게이지·기호도 비례 축소
- 코드 패널 `height-292u` → `height*0.745`, 램프 `height-150u` → `height*0.885`
- CLEAR 가로 버튼(화면 하단 한 층) → 램프 옆 아이콘 버튼(`⌫`, icon 토큰)

**패널 자산 (심각도 3)** — 프레임을 가득 채우도록 프롬프트 수정 후 재생성. 보이는 판이 이미지의 **41.6% → 92.6%**, 위 여백 29.1% → 3.7%. 영수증 재발급됨.

**게이지 부착 (심각도 4)** — 텍스처별 선체 상단 비율(`HULL_TOP`, 알파>64 실측)로 UI를 붙인다. 이전에는 스프라이트 경계 기준이라 여백이 큰 화물선만 게이지가 멀리 떴다.

**기호 색 (심각도 4)** — 모든 기호에 U+FE0E(텍스트 프레젠테이션)를 붙여 컬러 이모지 폴백을 차단.
