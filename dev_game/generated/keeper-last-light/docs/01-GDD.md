# 01-GDD — Keeper of the Last Light (등대지기: 마지막 항로)

> 이 문서는 `dev_game/dev-plan/implement_20260815_142904.md` 계획에 따라 작성되었다.
> 규칙 숫자의 단일 원본은 `src/game/config/keeperConfig.js`이며, 이 문서는 그 값을 반영한다
> (`factory:docs-runtime-sync-qa`가 양방향 일치를 검사한다).

## 한 줄 피치

안개 낀 바다에서 등대 불빛으로 신호 코드를 보내 배를 안전 항로로 인도하고, 여명까지 버틴다.

## 핵심 입력

한 손 조작. 화면 하단의 **신호 램프 버튼** 하나만 쓴다.

| 입력 | 의미 |
|---|---|
| 짧게 탭 (260ms 미만) | 단점 `▪` |
| 길게 누르기 (260ms 이상) | 장점 `▬` |
| CLEAR 버튼 | 잘못 입력한 코드를 통째로 지움 |

코드는 3~4개 펄스의 나열이다. 마지막 펄스를 넣는 순간 판정된다.

## 핵심 재미

배가 요구하는 것을 **읽고**, 그것을 **손끝의 리듬으로 번역**하는 순간의 긴장. 배가 여러 척 동시에 기다리면 무엇부터 답할지 고르는 판단이 겹친다. 안개가 짙어질수록 기호를 볼 수 있는 시간이 짧아진다.

## 실패 조건

난파 **3회**. 배의 인내심 게이지가 0이 되면 암초로 표류해 난파한다. 잘못된 코드를 보내면 인내심이 크게 깎인다.

## 승리 조건

스테이지 5(여명)까지 통과. 각 스테이지는 **정해진 척수를 안전하게 인도**하면 다음으로 넘어간다.

## 30초 루프

1. 수평선에서 배가 등장하고 머리 위에 요청 기호가 뜬다 (0~2초)
2. 플레이어가 하단 코드표에서 그 기호의 빛 코드를 확인한다 (2~4초)
3. 램프를 그 리듬대로 탭·홀드한다 (4~7초)
4. 정확 → 배가 항로로 진입, 링 FX + 점수 + 콤보 / 오답 → 인내심 급감, 차가운 섬광
5. 다음 배가 이미 대기 중이다 — 1로 돌아간다

## 1분(쉬움) / 5분(혼돈)

| 시점 | 상태 |
|---|---|
| 1분 (스테이지 1~2) | 동시 대기 1~2척, 코드 3펄스, 인내심 넉넉, 시야 맑음 |
| 5분 (스테이지 4~5) | 동시 대기 최대 4척, 코드 4펄스, 인내심 짧음, 폭풍으로 기호 표시 시간 단축 |

난이도는 **경과 시간과 스테이지 인덱스만** 참조한다. 플레이어가 회복할 수 있는 값(남은 인내심, 점수, 콤보)은 난이도 축으로 쓰지 않는다 — 결함 클래스 D 방지.

## 신호 코드표

| 요청 기호 | 의미 | 빛 코드 |
|---|---|---|
| ◀ | 좌현 변침 | `▪ ▪ ▬` |
| ▶ | 우현 변침 | `▬ ▪ ▪` |
| ⏸ | 감속·정박 대기 | `▪ ▬ ▪` |
| ⚓ | 입항 허가 | `▬ ▪ ▬` |
| ⚠ | 암초 경고 회피 | `▪ ▬ ▬ ▪` |

`⚠`는 스테이지 3부터 등장하는 4펄스 코드다.

## 점수·콤보

- 인도 성공: **100점** × 콤보 배수
- 콤보는 연속 성공마다 +1, 최대 배수 **×5**
- 오답 또는 난파 시 콤보 **초기화**
- 인내심이 절반 이상 남은 상태에서 성공하면 **신속 보너스 +50**

## 스테이지 진행

| 스테이지 | 배경 | 목표 척수 | 동시 대기 | 코드 길이 | 기호 표시 |
|---|---|---:|---:|---|---|
| 1 | 맑은 밤바다 | 4 | 1 | 3펄스 | 항상 표시 |
| 2 | 옅은 안개 | 5 | 2 | 3펄스 | 항상 표시 |
| 3 | 짙은 안개 | 6 | 3 | 3~4펄스 | 항상 표시 |
| 4 | 폭풍 | 7 | 4 | 3~4펄스 | 항상 표시 |
| 5 | 여명 | 6 | 3 | 3~4펄스 | 항상 표시 |

스테이지를 넘길 때마다 배경이 크로스페이드되고 "STAGE CLEAR" 배너가 뜬다.

## 실패/재시도

난파 3회 시 즉시 GameOver(패배). RETRY는 스테이지 1부터 완전 초기화한다 — 부분 리셋을 두지 않는다(결함 클래스 K 방지).

## 콘텐츠 목록

- 배경 5종(스테이지별 날씨)
- 선박 스프라이트 3종(화물선·어선·여객선) + 난파선 1종
- UI: 신호 램프 버튼, 일시정지, 코드 패널
- FX: 광선 펄스, 성공 링, 난파 섬광, 물보라
- 오디오: 홈/게임 BGM, 단점·장점 펄스음, 성공, 난파, 스테이지 클리어

## 첫 플레이 이해도

홈 화면과 도움말이 다음 5가지를 명시한다.

1. **목표** — 여명까지 배를 안전하게 인도한다
2. **승리** — 스테이지 5 통과
3. **패배** — 난파 3회
4. **첫 행동** — 램프를 짧게/길게 눌러 코드를 보낸다
5. **진행 지표** — 스테이지 / 인도한 배 수 / 남은 난파 허용치

도움말은 게임 중 언제든 열 수 있고, 열면 게임이 일시정지되며, 닫으면 원래 상태로 복귀한다.
