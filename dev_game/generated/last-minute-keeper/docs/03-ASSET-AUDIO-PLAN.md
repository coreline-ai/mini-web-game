# 03-ASSET-AUDIO-PLAN — Last Minute Keeper

모든 런타임 에셋은 이 게임을 위해 새로 생성되었고 프로젝트 안에 자족적으로 들어 있다.
공유·복사·심볼릭 링크 에셋은 없다(`assetIsolation.mode: per-game`).

## 취득 경로 — Path A

`asset-plan.json` → `factory:imagegen` → 생성 즉시 검증(엣지분산·고주파·색수·알파·hue) →
미달 시 사유를 프롬프트에 주입해 재시도 → 크로마 제거·침식·자홍 중화 → 런타임 WebP 수출 →
**생성 영수증 발급**(`outputSha256`/`runId`/`generatedAt`).

## 배경 규약

- 프롬프트에 **"골 안은 완전히 비어 있을 것 — 공·골키퍼·선수 없음"** 명시(클래스 B)
- **골라인이 화면 하단 3/4 지점**에 오도록 구도 지정 — 게임플레이 좌표의 근거가 된다.
  이걸 안 잡으면 오브젝트가 공중부양한다(직전 게임에서 실제로 발생)
- 한글·점수·버튼 문구는 이미지에 굽지 않는다
- 네이티브 출력이 제작 규격에 못 미치면 §2.0.5 Declared Resample 규칙 적용

## UI 규약

스코어보드는 **9-slice로 그린다**. `setDisplaySize`로 원본 비율을 깨뜨리면 테두리가 한쪽만
두꺼워지고 베벨이 뭉갠다(직전 게임 실측: 2.00:1 자산을 4.54:1로 늘려 좌우 1.47배). 프롬프트에
"테두리는 사방 같은 두께, 안쪽 필드는 평평하고 비어 있을 것"을 명시했다.

## 스프라이트 여백 규약

생성 후 텍스처별 **알파 여백을 실측해 `config/spriteMetrics.js`에 상수로 기록**한다.
스프라이트 경계로 UI·그림자를 붙이면 자산마다 다른 높이에 뜬다(직전 게임 실측: 여백 5~28%).

## 시트 정책

다프레임 스프라이트 시트는 **쓰지 않는다**. image_gen이 구조적으로 가장 자주 실패하는
주문(셀 경계 잘림)이고, 키퍼 자세는 3장 + 트윈으로 충분하다.

## 오디오

`scripts/make-audio.mjs`가 절차적으로 합성한다(외부 서비스 없음). 전부 44.1kHz.

| 파일 | 트리거 | 설계 |
|---|---|---|
| `shot-impact.wav` | 슛 발사 | 저역 스윕 + 짧은 노이즈 = 가죽 "퍽" |
| `punch.wav` | 펀칭 세이브 | 임팩트보다 짧고 높게, 고역 통과 |
| `catch.wav` | 캐치 세이브 | 임팩트가 죽고 가죽 마찰만 |
| `net-ripple.wav` | 실점 | 그물 마찰 + 느린 떨림 + **관중 탄식 스웰** |
| `whistle.wav` | 스테이지 전환 | 삼각파 + 구슬 롤링 변조 |
| `home-loop.wav` | 홈 BGM | 관중 웅성거림 + 낮은 코드 패드 |
| `gameplay-loop.wav` | 게임 BGM | 같은 세계에 **심장 박동 킥** 추가 |

품질 규약: 원샷은 피크 ≥ 0.75 · 시작/끝 진폭 < 0.01, 루프는 이음매 불연속 < 0.005이며
**영점 교차로 회전**시켜 첫 재생 클릭도 없앤다. BGM은 지연 로드한다.

## 오디오 상태 규약 (클래스 H)

BGM 핸들은 전역 하나. 같은 키가 재생 중이면 재생성하지 않는다. 일시정지·도움말에서 pause,
복귀에서 resume, 홈 이동·종료에서 stop. mute는 저장되는 전역 상태이며 SFX에도 적용된다.
