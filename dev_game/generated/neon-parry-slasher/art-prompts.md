# Art Prompts - Neon Parry: Blade Slasher

This file records the production asset prompts, roles, and visual constraints for `neon-parry-slasher`.

## Style Guide
- Dark cyberpunk aesthetic with high-contrast cyan `#00ffff` and magenta `#ff007f` neon accents.
- Solid dark backgrounds optimized for runtime alpha extraction and additive/screen blending.
- 9:16 mobile portrait framing with clean central gameplay space.
