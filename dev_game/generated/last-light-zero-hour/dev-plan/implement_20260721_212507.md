## 개발 목적

현재 무기 카드는 `선택 → 다음 자동 사격 시 발사 → 기관포로 복귀` 흐름과 하나의 공용 발사 쿨다운을 공유한다. 따라서 특수무기 카드를 눌러도 즉시 쓰이지 않거나, 특수무기 사용 중 기관포가 끊기는 체감 문제가 발생한다.

기관포는 기본 자동사격 채널로 계속 유지하고, 산탄·연쇄전격·로켓·레일은 카드 탭 즉시 독립적으로 발동하는 병렬 전투 루프로 변경한다.

## 개발 범위

- 기관포와 특수무기의 발사 시계/쿨다운을 분리한다.
- 특수무기 카드 탭을 `선택`이 아닌 `즉시 발동`으로 전환한다.
- 특수무기 발동 중에도 기관포 자동 조준·자동 사격을 유지한다.
- 카드별 충전·재사용·준비 상태를 명확하게 표시한다.
- 아크 코일은 대상이 없으면 충전을 소모하지 않고 안내한다.
- 정적 전투 계약 QA와 실제 브라우저 조작 QA를 수행한다.

## 제외 범위

- 신규 무기, 적, 스테이지, 영구 성장 수치 추가
- 네트워크/멀티플레이/서버 저장
- 기존 무기 피해량·충전량의 대규모 밸런스 재설계

## Phase 1 — 원인 고정 및 설계

- [x] `WeaponSystem`의 공용 `nextFire`가 모든 무기를 막는 원인을 확인한다.
- [x] 특수무기 `select()` 및 260ms 기관포 복귀 예약이 선택 상태를 덮어쓰는 흐름을 확인한다.
- [x] 기관포 자동사격 + 특수무기 독립 즉시 발동 구조를 확정한다.

### 자체 점검

- 특수무기 사용이 기관포의 다음 발사 시간을 변경하지 않아야 한다.
- 특수무기 실패 시 자원과 현재 전투 채널이 보존되어야 한다.

## Phase 2 — 병렬 발사 시스템

- [x] `WeaponSystem`에 기관포 전용 발사 시계와 특수무기별 재사용 시계를 도입한다.
- [x] `activateSpecial(id, aim)`을 구현해 카드 입력 시 즉시 발동한다.
- [x] 아크 코일의 표적 존재 여부를 비용 차감 전에 검사한다.
- [x] 기관포의 자동사격·과열·냉각을 특수무기와 독립 유지한다.
- [x] `GameScene`에서 최신 조준 벡터를 카드 발동에 전달한다.

### 자체 점검

- 산탄·연쇄전격·로켓·레일을 눌러도 기관포 탄환과 과열 수치가 계속 갱신되어야 한다.
- 연속 카드 탭에서 각 무기는 자신의 재사용 상태만 확인해야 한다.

## Phase 3 — 카드 HUD 및 피드백

- [x] 기관포 카드를 `AUTO` 상태로 표시한다.
- [x] 특수무기 카드에 `READY`/`충전 n%`/`재사용 n.n초` 상태를 표시한다.
- [x] 발동 직후 특수무기 모델 반동을 짧게 연출한 뒤 기관포 모델로 복귀한다.
- [x] 충전 부족·재사용·표적 없음 안내를 구분한다.

### 자체 점검

- 특수무기 발동 중 카드 선택 테두리가 기관포 자동 상태를 오해하게 만들지 않아야 한다.
